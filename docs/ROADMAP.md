# 로드맵

기준: 2026-07-25

## v0.1 — 완료 (검증됨)

터미널에서 `grmide`를 치면 브라우저에서 변경사항을 본다. 이것만으로 IDE를 켤
이유의 대부분이 없어진다.

- [x] `grmide` CLI — 저장소 루트 자동 탐색, 포트 자동 확보, 브라우저 실행
- [x] 터미널 요약 — 브랜치 · HEAD · 변경 규모 · 파일 목록 · 주소
- [x] 변경 파일 목록 — 충돌 / Staged / Changes 그룹, 상태 표시, +추가 −삭제 줄 수
- [x] side-by-side diff — 단어 단위 하이라이트, 컨텍스트 줄 수 조절, 줄바꿈 토글
- [x] **문법 강조** — 언어 플러그인 구조 (js/ts · vue · html · css/scss · json · java)
- [x] 보기 범위 — 변경 부분 / ± 8줄 / **파일 전체**. 선택은 저장된다
- [x] 변경 블록 간 이동 (↑ / ↓), 오른쪽 변경 위치 눈금, `j` / `k` 파일 이동
- [x] untracked 파일 내용 표시, 바이너리 파일 구분
- [x] 파일별 확인 체크 — 파일이 다시 바뀌면 자동 해제
- [x] 파일 감시 기반 실시간 갱신 (SSE) + 연결 끊김 표시
- [x] stage / unstage
- [x] 토큰 인증 + 경로 검증

범위 규칙을 다시 그은 단계. "편집이 없는 읽기 전용 IDE"를 기준선으로 삼고, 파일에

## v0.4 — AI 리뷰 루프 (완료)

IntelliJ가 구조적으로 못 하는 일. git에는 HEAD와 index만 있고 "리뷰 시점"이라는
개념이 없어서, AI가 계속 고치는 동안 이미 본 40개와 새로 바뀐 3개가 구분되지 않는다.

- [x] **기준점** — 워킹트리를 트리 객체로 굳혀 `refs/grmide/baseline`에 매단다
- [x] **새 변경 표시** — 기준점 이후 바뀌고 아직 확인 안 한 파일에 ● 표시
- [x] **새 변경만 필터** — 좌측 목록을 새 변경으로 좁힌다
- [x] **기준점 대비 diff** — 이미 확인한 변경은 컨텍스트로, 새 변경만 변경으로
- [x] **개별 확인** — 파일을 보다가 `✓ 확인`을 누르면 다음 새 변경으로 넘어간다
- [x] **전체 확인** — 모두 확인 처리하고 기준점을 새로 잡는다
- [x] **라인 코멘트 → AI에게 전달** — 줄 번호를 눌러 코멘트를 달고, `프롬프트 복사`로
      경로·줄 번호·그때 본 코드가 담긴 프롬프트를 클립보드에 담는다
- [x] **AI 변경의 위험 지점 표시** — 삭제된 테스트, 사라진 에러 처리, 새 `console.log`,
      의존성 변경, 크게 지워진 파일. 목록에 ⚠ 표시와 필터, diff 위에 신호 띠
- [x] **확인 상태를 서버에 저장** — localStorage는 포트가 바뀌면 다른 origin이 되어
      진행률을 잃었다. 코멘트와 같은 파일에 두고, 예전 브라우저 기록은 한 번 옮겨 온다

## v0.4 이후 — 좁은 폭에서 쓰기 (완료)

이 도구의 전제는 "터미널 옆에 브라우저"다. 그런데 그 폭(700~900px)에서 side-by-side는
양쪽이 다 잘려 읽히지 않았다. 전제와 기능이 어긋난 지점이라 먼저 처리했다.

- [x] **UI를 Apple 플랫폼 재료로 재설계** — 시스템 폰트·iOS 시스템 컬러·Xcode 팔레트.
      크롬은 iOS 문법을, 코드 영역의 밀도는 그대로
      ([ARCHITECTURE](ARCHITECTURE.md#겉모습은-apple-플랫폼의-재료를-그대로-쓴다))
- [x] **한 줄 보기 (inline diff)** — `− / +`를 한 컬럼에 순서대로. 번호 컬럼이 하나여서
      껍데기가 60px로 줄고 남는 폭이 코드가 된다. 처음 열 때 폭이 1100px 미만이면
      자동으로 고르고, 사용자가 한 번 고르면 그 값을 기억한다
- [x] 좁아지면 바에서 개수 표시 → 상태 배지 순으로 접는다 (컨테이너 질의)
- [x] **확인 이후 바뀐 것만 보기** (2026-07-28) — 기준점은 워킹트리 전체를 한 순간에
      굳히지만, 실제로는 파일마다 본 시점이 다르다. `확인`을 누른 파일만 그때 내용으로
      쌓는 트리(`refs/grmide/seen`)를 두고 툴바에서 `HEAD 대비 / 기준점 이후 / 확인 이후`
      를 고른다
      ([ARCHITECTURE](ARCHITECTURE.md#확인-시점--파일마다-내가-읽은-뒤가-다르다-2026-07-28))
- [x] **긴 문서에서 절로 가기** (2026-07-28) — 제목 앵커(GitHub와 같은 규칙), `#링크` ·
      `X.md#절` 이동, `목차` 토글. `scrollIntoView` 가 바깥 컨테이너를 밀어 탭 바를
      화면 밖으로 보내던 것도 함께 고쳤다
      ([ARCHITECTURE](ARCHITECTURE.md#긴-문서에서-절로-가는-길-2026-07-28))
- [x] **탭이 쌓이지 않게** (2026-07-28) — 한 번 누르면 미리 보기(자리를 대신한다),
      두 번 누르면 붙잡는다. `⌥⇧T`로 닫은 탭 되살리기. `⌥`+글자를 `event.code`로 보게
      고쳐 `⌥W`가 실제 키보드에서 동작한다
      ([ARCHITECTURE](ARCHITECTURE.md#한-번-누르면-대신하고-두-번-누르면-붙잡는다-2026-07-28))
- [x] **마크다운 미리보기** (2026-07-28) — `.md`를 그려서 본다. 라이브러리 대신 파서가
      블록 트리를 내놓고 Vue가 요소로 그려 `v-html`이 없다. 코드 펜스는 diff와 같은
      강조기를 쓰고, 문서 간 링크는 탭으로 열린다
      ([ARCHITECTURE](ARCHITECTURE.md#마크다운은-html이-아니라-트리로-그린다-2026-07-28))
- [x] **코드를 읽기 편하게** (2026-07-27) — 코드 영역을 캔버스에서 떼어 Xcode가 원래
      쓰는 표면·글자색으로 되돌리고(`#1f1f24` / `#dfdfe0`), `⌘+`/`⌘-`로 코드 글자
      크기를 11–17px에서 조절한다. 밀도 비율은 고정이라 배율만 움직인다
      ([ARCHITECTURE](ARCHITECTURE.md#코드-표면은-캔버스보다-밝다-2026-07-27))

## v0.5 — AI와의 소통 (2026-07-26 재편)

**방향을 다시 잡았다.** 이건 git IDE가 아니다. 기능을 고를 때 기준은 "git에 있는
기능인가"가 아니라 **"AI와 주고받는 일이 나아지는가"** 다. 원래 v0.5였던 커밋
묶음은 아래로 내렸다 — 커밋도 결국 AI에게 시키게 되므로 브라우저에 그 UI를 만드는
값이 낮다 ([CLAUDE.md](../CLAUDE.md#이건-git-ide가-아니다-2026-07-26-방향-확정)).

- [x] **이미지 미리보기** — png·jpg·gif·webp·avif·bmp·ico·svg를 이전/이후로 나란히.
      용량과 픽셀 크기 변화를 함께 알린다. `git diff`가 "Binary files differ" 한 줄만
      주는 구간이라 터미널에서는 확인할 방법이 없었다. 기준점 대비·커밋 diff·⌘P
      파일 보기에서 모두 동작한다
- [x] **리뷰 스레드를 한 곳에서** — 코멘트를 파일별로 모아 보고, 보낼 것만 골라
      프롬프트로 넘긴다. 상단 `리뷰 N`으로 연다
- [x] **컨텍스트 담기** — 파일·구간·검색어를 바구니에 담아 프롬프트로 넘긴다.
      diff 바의 `담기`, 줄을 끌어 고른 뒤 `구간 담기`, 검색 결과에서 `⌥Enter`.
      내용은 넘길 때 읽고, 검색어는 넘길 때 다시 검색한다
- [x] **코멘트가 반영됐는지 되짚기** — 코멘트를 쓸 때 저장해 둔 코드 조각이 지금도
      파일에 있는지로 "아직 / 반영됨"을 판정한다. 줄 번호가 밀려도 따라가고,
      삭제된 쪽 코멘트는 방향이 뒤집힌다. `반영된 N개 정리`는 사람이 누른다
- [x] **사이클 요약** — 기준점 이후 무엇이 바뀌고 무엇이 남았는지 한 장으로.
      코드가 무엇을 하는지는 적지 않는다(그건 AI가 안다) — 사람이 확인한 것,
      남은 것, 아직 반영 안 된 코멘트, 위험 신호처럼 **AI가 알 수 없는 것**만 모은다

- [ ] hunk / 줄 단위 stage (`git add -p` 대체)
