# 로드맵

기준: 2026-07-25

## v0.1 — 완료 (검증됨)

터미널에서 `gitshow`를 치면 브라우저에서 변경사항을 본다. 이것만으로 IDE를 켤
이유의 대부분이 없어진다.

- [x] `gitshow` CLI — 저장소 루트 자동 탐색, 포트 자동 확보, 브라우저 실행
- [x] 변경 파일 목록 — 충돌 / Staged / Changes 그룹, 상태 표시, +추가 −삭제 줄 수
- [x] side-by-side diff — 단어 단위 하이라이트, 컨텍스트 줄 수 조절, 줄바꿈 토글
- [x] **문법 강조** — 언어 플러그인 구조 (js/ts · vue · html · css/scss · json)
- [x] 보기 범위 — 변경 부분 / ± 8줄 / **파일 전체**. 선택은 저장된다
- [x] 변경 블록 간 이동 (↑ / ↓), 오른쪽 변경 위치 눈금, `j` / `k` 파일 이동
- [x] untracked 파일 내용 표시, 바이너리 파일 구분
- [x] 파일별 확인 체크 — 파일이 다시 바뀌면 자동 해제
- [x] 파일 감시 기반 실시간 갱신 (SSE) + 연결 끊김 표시
- [x] stage / unstage
- [x] 토큰 인증 + 경로 검증

## v0.2 — 커밋까지 브라우저에서 끝내기

여기까지 오면 "변경 확인 → 커밋" 한 사이클이 브라우저에서 닫힌다.

- [ ] **커밋** — 메시지 입력, amend, 커밋 후 목록 갱신
- [ ] **hunk / 줄 단위 stage** — `git add -p` 대체. 터미널에서 가장 짜증나는 작업
- [ ] **파일 되돌리기** (checkout --) — 되돌리기 전 확인 필수
- [ ] 커밋 메시지 초안 생성 (diff 기반)

## v0.3 — 히스토리

- [ ] **git log 그래프** — 브랜치 토폴로지. `--graph`가 판독 불가해지는 지점을 해결
- [ ] **커밋 상세** — 변경 파일 목록 + diff (같은 뷰어 재사용)
- [ ] **파일 히스토리** — 이 파일의 커밋 이력, 커밋 간 diff
- [ ] **git blame** — 코드 옆 인라인 표시, 해당 커밋으로 점프
- [ ] **브랜치 간 비교** (`main...HEAD`) — PR 올리기 전 전체 확인

## v0.4 — 충돌과 stash

- [ ] **3-way merge 충돌 해결 UI** — 터미널에서 최악인 작업. IDE를 켜는 큰 이유
- [ ] stash 목록 + 내용 미리보기, apply / drop

## v0.5 — 인덱싱과 검색

최소한의 git 기능이 완성된 뒤에 착수한다 (사용자 지시).

- [ ] 코드 검색 — 워킹트리 전체 텍스트 검색
